# 📋 Dastavej-TestCases

A professional **Software Development Engineer in Test (SDET)** portfolio project focused on manual testing, API testing, and UI automation for the **Dastavej** authentication module.

## Project Overview

Dastavej is a secure digital document locker application. This repository contains the complete QA deliverables created to validate its authentication system, following an industry-style testing workflow.

## Scope

**Authentication Module**

* User Registration
* Email OTP Verification
* Login
* Logout
* Protected Dashboard Access
* JWT Refresh Token
